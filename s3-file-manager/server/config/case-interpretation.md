# 船舶险反欺诈结果解读案例（范例）

> 本范例源自《船舶险反欺诈-案例及指标解读.xlsx》，展示人工核保人对查询结果的解读思路与报告风格，供 AI 生成报告时对齐。

## 案例船舶：鸿航169（识别号 CN20102397742）

鸿航169 过往3年投保的险种分别为保赔险、油污险、船壳险（一船3行）。

### 一、赔付情况

以保赔险数据为例：
- 已决赔付率显示"0,0,0,0"，分别代表 2026年（当年）、2025年、2024年、2023年（过往三年）的已决赔付率为 0。
- 已决+未决赔付率显示"0,44,0,0"，2025年对应已决+未决的赔付率是 44%，而 2025年的已决是 0。这代表 2025年的保单存在一起未决赔案，未决赔付率是 44%。

鸿航169 的船壳险：虽然当年及过往3年的已决赔付率为 0，但 2025年未决赔付率为 219%、2023年未决赔付率为 180%，说明该船仍存在多个未决案件，承保亏损风险高。

### 二、出险情况

- 近3年出险原因及数量："其他意外事故|1,触碰|1,触碰(船舶以外物体)|1,雷击|1"——近3年船壳险共出险4次，原因分散。
- 近3年赔案金额：527809.2 元（累计52.8万）。
- 近3年赔案区间及案件数量："10万以下|1,10-30万|3"——4个赔案中1个10万以下、3个10-30万。

### 三、起保当月出险

- 起保当月出险占比需重点关注：若显示"1,100%"代表上年保单在起保当月即出险，存在较高欺诈风险（倒签单嫌疑）；显示"0,0.00%"代表未在起保当月出险。

### 四、保险公司转保

- 近3年保单涉及保险公司数量：1=同一家承保，客户稳定；2=涉及变更，需关注；3=频繁变更，多为渠道业务或高赔付业务，需重点关注。

### 五、单均保额保费

- 船壳险单均保额保费"35000000,148000"：单均保额3500万、单均保费14.8万，平均费率4.22‰。保额数值完整说明过往3年保额、费率、保费大概率保持不变。
- 油污险单均保额保费"5566667,7553"：保额数字零碎，说明油污险保额曾涉及调整。油污险和保赔险一般按总吨位计算保费。

### 六、综合判断思路

1. 先看赔付率（已决 vs 已决+未决）识别未决赔案与承保亏损；
2. 看出险原因是否集中、赔案金额与区间判断损失严重度；
3. 看起保当月/2月/3月出险占比识别倒签单欺诈信号；
4. 看保险公司数量识别频繁转保的高赔付客户；
5. 看单均保额保费识别保额异常调整。
