# 结果文件目录（download/）

> 注意：`download/` 现在指 **S3 上的目录（前缀）**，不是本机文件夹。
> 第三方把查询结果文件上传到 S3 桶的 `download/` 目录下，系统从这里检索并导入。
> 可用环境变量 `RESULT_S3_PREFIX` 覆盖该前缀（默认 `download/`）。

## 触发导入
在「船舶查询」页 → “手动触发（上传 / 检索导入）”面板，选择**结果日期**后，
点击 **检索并导入返回结果 Excel** 按钮：
1. 将结果日期 `YYYY-MM-DD` 自动转为紧凑格式 `YYYYMMDD`；
2. 在 S3 的 `download/` 目录下，匹配文件名含 `_YYYYMMDD` 且以 `_result.xlsx` 结尾的文件；
3. **仅下载并导入第一个匹配文件**（不下载全部）；
4. 解析入库，并把该文件记入 `processed_results` 去重。

## 支持的结果文件命名格式
- 实际格式：`{机构}_{YYYYMMDD}{分公司名}_result.xlsx`
  - 例如 `A01_000001_20240603甘肃分公司_result.xlsx` → 机构 = `A01_000001`，日期段 = `20240603`
- 旧格式（兼容）：`{机构}_{YYYY-MM-DD}result.xlsx`

## 本机这个 download/ 文件夹
本目录仅保留此说明文件，不再被程序读取（旧的“本地固定结果文件导入”功能已移除）。
