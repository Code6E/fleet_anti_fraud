### 报告弹窗三增强（v1.3g）
按用户截图需求给「查看报告」弹窗加 3 个功能：
1. **下载中银保信返回数据 Excel**：`db.js` schema 升 v4（无破坏性）；`excel.js` 新增 `buildShipDataExcel`——由 `ship_policy_results.raw_json` 还原该船全部原始信息列（18 列，列名/顺序与返回文件一致，raw 缺失退回结构化字段兜底）；`ships.js` 新增 `GET /:id/export-data`（RFC5987 中文文件名 `船舶数据_船名.xlsx`）
2. **下载 AI 报告**：`GET /:id/export-report` → Markdown 文件（含船舶信息头/风险等级/命中规则/正文），前端报告标题行加「⬇ 下载AI报告」
3. **人工评价/评级**：`ai_feedback` 表（rating 1-5 星 + accuracy 准确/部分准确/不准确 + comment ≤500，同人同船保留最新）；`GET|POST /:id/feedback` 含聚合统计（N 人评价·平均 X.X 星）；前端 `ReportFeedback` 组件（可点星级 + 标签 chips + 评语，支持更新重提）
