> 交付要求：4 分钟左右，需展示**实操流程、应用成果、建设思路、功能模块**。
> 本脚本按「30 秒讲清为什么 + 2 分钟真操作 + 1 分钟讲模块与成果」编排，口播全文约 1020 字，正常语速（4 字/秒）约 4'05"，含 3 处可删句可压到 3'50"。

## 一、整体编排逻辑（先说清为什么这样排）

评审的四项要求，用一条**业务时间轴**串起来，不做功能罗列：

```
痛点（30s）→ 思路（20s）→ 机构端实操：查询→命中→新船入队（2'00"）
     → 后台 AI Agent：汇总上传→T+1返回→AI解读（35"）
     → 成果交付：报告/水印/下载/评价（30"）→ 权限隔离（15"）→ 价值数据（18"）
```

| 评审要求 | 对应镜头 | 展示手法 |
|---|---|---|
| 建设思路 | S3 | PPT 动画 + 一句话概括"重复交给 AI、判断留给人" |
| 功能模块 | S4/S5/S6/S7/S8/S9 + S10 模块表 | 不用 PPT 罗列，**每个模块都在实操里露一次脸**，最后用一张表回扣 |
| 实操流程 | S5→S6→S7→S8（占全片 55%） | 真实系统、真实数据、一镜到底分段录制 |
| 应用成果 | S7（日志/去重）、S10（四个数字） | 屏幕贴片数字 + 全量库真实统计 |

**关键原则**：能录界面就不放 PPT。PPT 只用来讲背景和思路（S1–S3），控制在 60 秒内，其余全部是系统实操——这是"演示视频"区别于"路演视频"的核心。

## 七、评委高频追问（建议答在片尾或备注页）

- **和直接用 S3 客户端比，优势在哪？** 不是替代数据源，而是把"装、汇总、命名、踩点、捞文件、解读"六段人工环节自动化 + 全司数据资产化复用。
- **数据会不会串？** 船舶风险数据全司共享（只读），查询行为/文件/队列按机构服务端隔离，命中复用只读共享层，不触碰其他机构任何信息。
- **AI 不靠谱怎么办？** 规则引擎（R1–R6，阈值写在 `interpret-rules.json`，改规则不动库）先出确定结论，大模型只做自然语言组织；LLM 不可用自动降级为规则版报告，**评级词只取规则引擎结果，禁止模型改判**；人工评价回流持续校准。
- **成本？** 去重直接减少按次计费的返回条数；命中复用免重复查询；服务端零依赖部署（Express + SQLite），无新增算力采购。
- **推广性？** 换 `SERVICE_NO` 与入参/结果模板即可复用到其他中银保信查询服务；账号体系已支持总公司/分公司/中支三级。
