# 字段解读规则

智盾查询数据各字段的口径与陷阱。生成报告前必读——字段格式有若干反直觉之处，误读会直接导致核保结论错误。

## 数据表结构

一条船可能占 **1~3 行**，每行一个险种小类（船壳险 / 保赔险 / 油污险）。船舶基础信息（识别号、IMO号、船名）在多行间重复，险种字段则各行独立。脚本的 `regroup_by_ship()` 会把它们重组为「一船一档 + 每险种一组指标」。

统计区间：**当年及过去三年**，共 4 个保单年度。

## 特殊值

| 值 | 含义 | 陷阱 |
|---|---|---|
| `(null)` | 该字段在统计区间内无数据（未出险 / 无投保记录） | 不等于 0。赔案金额为 `(null)` 表示没出过险，写 0 会误导 |
| `Z` | 该年度**无投保记录** | 出现在赔付率字段中，代表该年度没有保单，不是赔付率为 0 |
| `0` | 有保单但无赔付 | 与 `Z` 含义完全不同 |

整行全为 `(null)` 的船 = 过往3年完全无投保记录。这类船**不能评为低风险**（没有任何数据支撑「优质」结论），脚本评为中性灰色「无数据」。

## 赔付率字段（最关键，也最易误读）

两个字段必须**结合着看**：

- `当年及过去3年满期赔付率（已决）`
- `当年及过去3年满期赔付率（已决+未决）`

### 四位数字的顺序

逗号分隔的四个值，从**当年往前推**：

```
2026年（当年）, 2025年, 2024年, 2023年
```

顺序会随当前年份变化，脚本按 `--current-year` 动态计算，不要写死。

### 已决 vs 已决+未决

- **已决**：已结案赔付金额 ÷ 满期保费
- **已决+未决**：（已结案赔付 + 立案未决估损）÷ 满期保费

两者之差 = 未决估损占比。**这是发现隐藏赔案的关键**：

> 示例：某船保赔险已决 `0,0,0,0`，已决+未决 `0,0,0,388`。
> 2023 年已决为 0 但已决+未决高达 388% → 该年度有一起**尚未结案**的赔案，估损约为满期保费的 3.88 倍。
> 只看已决会得出「三年零赔付」的错误结论。

### 数值上限

显示最大值 **500**，代表赔付率超过 500%。当年或去年任一数值 >500% 时提示高风险——存在**出险后转保**的可能。

### 未决估损金额估算

```
估损 ≈ (已决+未决 − 已决) 百分点 ÷ 100 × 单均保费
```

取整到万元。**必须标注为估算值**，注明「实际以理赔系统立案估损为准」。

表述规范：**直接给绝对值**（「估损金额约44万元」），**禁止**写成「约为满期保费的3.88倍」——倍数换算被核保人评价为不专业。

## 出险原因及数量

格式 `出险原因|数量`，逗号分隔多项：

```
其他意外事故|1,触碰|1,触碰(船舶以外物体)|1,雷击|1   → 近3年出险4次
意外事故类|2                                    → 近3年出险2次，原因均为意外事故类
(null)                                          → 统计区间内未出险
```

**重要**：出险原因**没有行业统一码值**，每家公司有自己的分类体系。以表格实际展示为准，不要试图归一化或映射到标准码表。同一类事故在不同公司可能记为「触碰」「触碰(船舶以外物体)」「意外事故类」。

分隔符用 `|` 而非 `:`，且原因文本本身可能含括号，解析时按**最后一个** `|` 切分。

## 赔案区间及案件数量

格式同 `区间|数量`：

```
10万以下|1,10-30万|3   → 共4件赔案，1件在10万以下，3件在10~30万之间
```

区间边界文本（「10万以下」「10-30万」）由数据源决定，原样引用，不要改写成自己的分档。

## 起保期出险字段（欺诈风险核心）

三个字段衡量「投保后多快出险」——越快出险，欺诈嫌疑越大：

| 字段 | 高风险信号 |
|---|---|
| 近1年起保当月出险保单数量及占比 | 非 `0,0.00%` → **高风险** |
| 近1年起保2个月出险保单数量及占比 | 非 `0,0.00%` → 中风险 |
| 近1年起保3个月出险保单数量及占比 | 非 `0,0.00%` → 中风险 |

格式 `数量,占比`，如 `1,100%` 表示上年保单在起保当月即出险。三者全为 `0,0.00%` → 低风险。

典型欺诈模式：出险后换公司投保，新保单起保当月就报案。

## 保险公司数量与转保

```
(null) → 过往3年无投保记录
1      → 均在同一家承保，客户稳定性较高
2      → 变更过一次，需结合赔付率字段关注
3      → 频繁变更，多为渠道业务或高赔付业务，**重点关注**
```

`最近保单涉及保险公司代码` 需查机构代码表翻译成全称。**报告正文只写机构全称，不写代码。**

## 单均保额保费

```
近3年单均保额, 近3年单均保费    （两个独立列，单位：元）
```

### 费率口径按险种区分

| 险种 | 公式 | 单位 |
|---|---|---|
| 保赔险、油污险 | 单均保费 ÷ **总吨位GT** | 元/GT |
| 船壳险 | 单均保费 ÷ 单均保额 | ‰ |

保赔险和油污险**按总吨位计收保费**，所以必须知道 GT 才能算费率。船壳险一般仅统计主险保额（可能另有附加险），费率仅供参考。

### 已验证的基准值

用示例船反推，与总公司模板记载完全吻合：

```
保赔险: 45318 ÷ 1743GT   = 26.00 元/GT   ✓ 模板记 26 元/gt
油污险: 7553  ÷ 1743GT   =  4.33 元/GT   ✓ 模板记 4.33 元/gt
船壳险: 148000 ÷ 35000000 = 4.23‰        ✓ 模板记 4.23‰
```

### 从数值形态判断承保方案是否调整

这是模板里的解读技巧：

- 保额为**完整整数**（如 35000000 = 3500万）→ 保额大概率未变，方案稳定
- 保额**有零头**（如 5566667）→ 保额涉及调整
- 保费为**完整数值**（如 148000 = 14.8万）→ 保费稳定
- 保费**有零头**（如 114502）→ 可能受保单数量或承保方案微调影响

脚本按「保额 % 10000 == 0 且保费 % 1000 == 0」判断。**这是定性推断，须在文中标注「本段为定性判断，非事实陈述」。**

## 船龄推算

船舶识别号格式 `CN` + **四位建造年份** + 序列号：

```
CN20102397742  → 2010 年建造 → 2026 − 2010 = 16 年
CN20104302285  → 2010 年建造 → 2026 − 2010 = 16 年
```

已用模板示例船验证（模板记载鸿航169船龄16年，推算吻合）。

**注意**：按当前年份动态计算，不要写死 2026。识别号缺失或格式不符时返回「待补充」，不要猜。

## 风险评估完整条款

### 业务品质

**高风险（红）**——满足任一：
1. 涉及 3 个险种，且所有险种「已决+未决」中任意 4 个数值超过 100
2. 任一险种「已决+未决」的**前两个数值**（当年、去年）中任意一个超过 500（存在出险转保可能）
3. 所有险种「近3年出险原因及数量」合计数量超过 3

**低风险（绿）**——须**同时**满足：
1. 所有险种「已决+未决」所有数值均低于 55
2. 所有险种「近3年出险原因及数量」合计数量 ≤ 1
3. 所有险种「近3年赔案金额」合计低于 10 万

**中风险（黄）**——不属于高风险也不属于低风险的其余情形。

### 欺诈风险

- **低风险（绿）**：三个起保期出险字段所有数值均为 `0,0.00%`
- **中风险（黄）**：起保2个月或3个月字段任一为 `0,0.00%`（即未全部命中低风险，但当月起险仍为0）
- **高风险（红）**：任一险种「起保当月出险」字段不是 `0,0.00%`

### 评级展示

报告第五节**只写评级结果，不写评级依据**（依据通过对话解释）。评级词单独成 run、加粗、着色：

| 等级 | 色值 | 说明 |
|---|---|---|
| 低风险 | `00A651` | 绿 |
| 中风险 | `D6A419` | 琥珀黄。**不用纯黄**——白底与黑白打印下不可读 |
| 高风险 | `E02020` | 红 |
| 无数据 | `808080` | 中性灰。过往3年无投保记录时使用 |
